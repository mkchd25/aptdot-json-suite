# Security policy

## Supported versions

Only the latest release, which is the version running on [aptdot.com](https://www.aptdot.com/), receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Preferred: use GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/mkchd25/aptdot-json-suite/security) of this repository. Only the maintainer can see the report.
- Or use the [Aptdot contact page](https://www.aptdot.com/contact-us/) and mention "security" in the subject.

Please include the steps to reproduce, the browser and version, and a sample input or link. Use dummy data only, never real secrets.

We aim to reply within 7 days and will credit you in the changelog if you wish.

## Scope

In scope: the code in this repository and the JSON tools on aptdot.com that use it, for example script injection, data being sent somewhere it should not be, or crashes caused by crafted input.

Out of scope: advertising and analytics scripts on aptdot.com, browser extensions, and reports that need physical access to the user's device.
